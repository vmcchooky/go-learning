Kiểu số, bool & literals
int, uint, float, complex, bool, numeric literals và conversion
▼
int8/16/32/64float32/64complexboolcơ bản
var a int8 = 127         // -128..127
var b uint64 = 1 << 63  // unsigned
var c int = 42          // 32 hoặc 64 bit tùy kiến trúc
var f32 float32 = 3.14
var f64 float64 = 3.1415926535
z := complex(2, 3)      // 2 + 3i
ok := true

hex := 0xff

sep := 1_000_000

fmt.Println(5 / 2)          // 2: chia số nguyên bị cắt phần lẻ
fmt.Println(float64(5) / 2) // 2.5

var x int = 10
var y int64 = int64(x) // conversion phải explicit
Ý chính: Go có hệ kiểu số khá rõ ràng: integer, unsigned integer, floating-point, complex, và bool. Phép chuyển kiểu giữa các loại số gần như luôn phải viết explicit.
Quy tắc cần nhớ: int và uint phụ thuộc kiến trúc máy. Nếu dữ liệu cần kích thước cố định khi lưu file, network, hoặc binary format, hãy ưu tiên các kiểu như int32, uint64.
Lỗi hay gặp: Nhiều người mới bị bất ngờ vì 5 / 2 cho ra 2 chứ không phải 2.5. Overflow cũng có thể xảy ra nếu chọn kiểu quá nhỏ như int8.
Khi nào dùng: Dùng int cho tính toán thông thường trong app. Dùng kiểu width cố định khi cần format dữ liệu rõ ràng hoặc tương thích hệ thống khác.
String, byte & rune
UTF-8, immutability, len theo byte, rune theo code point
▼
stringbyteruneUTF-8cơ bản
s := "Hello, 世界"

fmt.Println(len(s))                    // số bytes, không phải số ký tự
fmt.Println(utf8.RuneCountInString(s)) // số rune thực

b := s[0]          // byte đầu tiên: 'H'
r := '世'          // rune literal = int32
rs := []rune(s)    // convert để sửa theo ký tự
rs[0] = 'h'
s2 := string(rs)

raw := `C:\Go\learn` // raw string literal

for i, r := range s {
    fmt.Println(i, r)
}
Ý chính: String trong Go là immutable và được lưu dưới dạng UTF-8. byte thường đại diện cho dữ liệu nhị phân hoặc ASCII, còn rune đại diện cho Unicode code point.
Quy tắc cần nhớ: len(s) trả về số bytes. Nếu cần đếm ký tự Unicode, dùng utf8.RuneCountInString hoặc chuyển sang []rune.
Lỗi hay gặp: Sửa trực tiếp s[0] là không hợp lệ vì string immutable. Người mới cũng hay nhầm một ký tự Unicode luôn bằng một byte, nhưng UTF-8 có thể dùng nhiều byte cho một rune.
Khi nào dùng: Dùng string cho text, []byte cho I/O, file, network, hoặc dữ liệu cần mutate theo byte.
Type alias, defined type & conversion
type T U, type T = U, conversion, parsing và string conversion
▼
typealiasconversionparsingtrung cấp
// Defined type — tạo type mới
type Celsius float64
type Fahrenheit float64

var c Celsius = 100
// var f Fahrenheit = c // ERROR: khác type
var f Fahrenheit = Fahrenheit(c*9/5 + 32)

// Type alias — hoàn toàn giống type gốc
type MyInt = int
var x MyInt = 5
var y int = x // OK

// Conversion khác với parsing
n := int64(42)
s := strconv.FormatInt(n, 10) // "42"
i, err := strconv.Atoi("123")
_ = i
_ = err

// Cẩn thận: string(65) = "A", không phải "65"
fmt.Println(string(65))
Ý chính: type T U tạo một type mới, còn type T = U chỉ tạo alias cho type cũ. Conversion là đổi representation theo quy tắc ngôn ngữ, còn parsing là đọc dữ liệu text thành giá trị.
Quy tắc cần nhớ: Hai defined type khác nhau không gán trực tiếp cho nhau dù cùng underlying type. Khi muốn chuyển, phải viết explicit conversion.
Lỗi hay gặp: Nhiều người nhầm string(65) với `"65"`, nhưng kết quả là ký tự Unicode tương ứng, tức `"A"`. Muốn đổi số thành chuỗi số, dùng strconv hoặc fmt.
Khi nào dùng: Dùng defined type khi muốn tạo ngữ nghĩa riêng cho domain như UserID, Celsius. Dùng alias khi cần tương thích ngược hoặc đổi tên type mà vẫn giữ nguyên identity.
Type assertion & type switch
i.(T), comma-ok, switch v.(type) với interface values
▼
type assertiontype switchinterfacetrung cấp
var v any = "hello"

s := v.(string)         // OK nếu chắc chắn đúng type
s2, ok := v.(string)    // comma-ok an toàn hơn
n, ok := v.(int)        // ok = false, n = 0
_ = s
_ = s2
_ = n

func describe(i any) string {
    switch v := i.(type) {
    case int:
        return fmt.Sprintf("int: %d", v)
    case string:
        return fmt.Sprintf("string: %q", v)
    case []byte:
        return fmt.Sprintf("bytes: %d", len(v))
    case nil:
        return "nil"
    default:
        return fmt.Sprintf("unknown: %T", v)
    }
}
Ý chính: Type assertion và type switch chỉ áp dụng cho giá trị interface như any. Chúng cho phép lấy giá trị concrete bên trong interface khi bạn cần xử lý theo type thực tế.
Quy tắc cần nhớ: v.(T) sẽ panic nếu giá trị bên trong không phải T. Nếu không chắc chắn, hãy dùng dạng x, ok := v.(T).
Lỗi hay gặp: Nhiều người cố assertion trên biến không phải interface, hoặc quên comma-ok rồi gặp panic ở runtime.
Khi nào dùng: Dùng khi làm việc với API nhận any, decode dữ liệu động, middleware, reflection-lite, hoặc xử lý nhiều loại giá trị trong cùng một luồng.
Comparable, any & constraints
comparable, any, union types, underlying type với ~
▼
comparableanyconstraints~trung cấp
// any = interface{}
func Print(v any) { fmt.Println(v) }

// comparable — có thể dùng == và !=
// slice, map, func KHÔNG comparable
func Contains[T comparable](slice []T, item T) bool {
    for _, v := range slice {
        if v == item {
            return true
        }
    }
    return false
}

// Union constraint
type Number interface {
    ~int | ~int32 | ~int64 | ~float32 | ~float64
}

// Underlying type với ~
type MyInt int
type Integer interface { ~int }
// MyInt thỏa mãn Integer vì underlying = int
Ý chính: any là alias của interface{}. Trong generics, constraints giúp mô tả tập type được phép dùng làm type parameter.
Quy tắc cần nhớ: comparable dùng cho các type có thể so sánh bằng == và !=. ~T nghĩa là chấp nhận mọi type có underlying type là T.
Lỗi hay gặp: slice, map, và func không thỏa comparable. Nhiều người cũng nhầm any là “dynamic typing”, nhưng Go vẫn kiểm tra type rất chặt.
Đọc sau: Khi dùng generics thực tế, bạn sẽ gặp thêm các constraints như cmp.Ordered hoặc custom constraints theo domain của project.
Channel types
chan, chan<-, <-chan, buffered/unbuffered, nil và close
▼
chanbuffereddirectionaltrung cấp
var nilCh chan int // zero value = nil
_ = nilCh

// Unbuffered: send/receive phải bắt tay trực tiếp
ch := make(chan int)

// Buffered: chứa được tối đa capacity phần tử
bch := make(chan string, 2)
bch <- "a"
bch <- "b"
close(bch)

// Directional channels
var send chan<- int = ch  // send-only
var recv <-chan int = ch  // receive-only
_ = send
_ = recv

for v := range bch { // đọc đến khi channel bị close
    fmt.Println(v)
}

// Check if channel has value
v, ok := <-bch // sau khi close và đọc hết: v = zero value, ok = false
fmt.Println(v, ok)
Ý chính: Channel là một type cốt lõi của Go cho giao tiếp giữa goroutines. Unbuffered channel đồng bộ send/receive, còn buffered channel cho phép chứa tạm một số phần tử.
Quy tắc cần nhớ: Receive từ channel đã đóng sẽ trả về zero value cùng ok = false. range ch sẽ dừng khi channel bị đóng.
Lỗi hay gặp: Gửi vào channel đã đóng sẽ panic. Gửi/nhận trên nil channel sẽ block mãi. Đây là các bug concurrency rất phổ biến với người mới.
Khi nào dùng: Dùng channel khi bạn thật sự cần giao tiếp hoặc đồng bộ giữa goroutines. Nếu chỉ cần bảo vệ dữ liệu dùng chung, đôi khi Mutex đơn giản hơn.
